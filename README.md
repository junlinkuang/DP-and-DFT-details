# DP-and-DFT-details
The repository is organized into two main directories: DFT (density functional theory calculations) and DP (deep-potential).

# DFT

## 1. Optimized_Structures
This folder contains the 24 optimized structures obtained from PBEsol calculations, corresponding to the structures reported in the paper.

**File description:**
- Optimized structure files (PBEsol-relaxed configurations)
- INCAR and POTCAR files for four different pseudopotentials used in the calculations

## 2. Phonon
This folder contains the phonon calculation results for five low-energy structures.

**File description:**
- phonon_band_DFT.txt : phonon dispersion from DFT (phonopy)
- phonon_band_DP.txt   : phonon dispersion from the trained DP model
**Format:**
  Column 1 : cumulative distance along the k-path
  Column 2 : phonon frequency (THz)

## 3. BECs
This folder contains the Born effective charges (BECs) calculated for the structures/conditions listed below.

**File description:**
Files are named as <condition>_<phase> or <temperature>-<electric field>, e.g. 0K_R3c, 400K-420kV_cm.
- 0K_R3c.txt: R3c phase at 0 K
- 0K_Pnma-AFE20.txt: Pnma phase with AFE20 configuration at 0 K
- 0K_Cubic.txt: cubic phase at 0 K
- 0K_Pbam.txt: Pbam phase at 0 K
- 400K-420kV_cm.txt: Cubic phase at 400 K under an electric field of 420 kV/cm
- 400K-540kV_cm.txt: Cubic phase at 400 K under an electric field of 540 kV/cm
  
**Note:**
All files were computed with 0 K DFPT. The four 0 K files use the respective 0 K structures, while the two 400 K files use cubic-phase structures at 400 K under finite electric fields (420 and 540 kV/cm).

**Format:**
  Each ion is listed as a 3×3 Born effective charge tensor (in e):
  ion index followed by three rows of Z*_ij (i, j = x, y, z).

# DP

## 1. Model
This folder contains the trained deep potential model and related training outputs.

**File description:**
- graph-compress.pb: compressed frozen graph model, ready for inference in LAMMPS
- input.json: training input parameters
- lcurve.out: learning curve output

## 2. Training set
This folder contains the training dataset.

**Subfolders:**
- dp-interp: data generated by interpolation/perturbation, containing *.raw files with energies, forces, and virials
- dp-temp: data generated from finite-temperature MD simulations, containing *.raw files with energies, forces, and virials

## 3. Test
This folder contains the test dataset used to evaluate the model's performance.

**Subfolder:**
- dp-testing: Test dataset containing *.raw files (energies, forces, virials).

## 4. Validation
This folder contains the model evaluation results.

**Subfolders:**
- Training_results: Error evaluation on the training set (contains standard dp test outputs: results.e.out, results.f.out, results.v.out, etc.).
- Test_results: Error evaluation on the test set (same file format as above).
- Pnma-AFE20-400K: Finite-temperature validation data for the Pnma phase at 400 K, including the original *.raw data files and the evaluation outputs (result.e.out, result.f.out, result.v.out, etc.).

## 5. LAMMPS
This folder contains the LAMMPS input and MD simulation data for different phases (Pbam, Pnma20, Cubic, R3c, and lattice).

**File description:**
- input.lammps: The main LAMMPS input script.
- Phase subfolders: Each contains the MD simulation outputs for different AFD (antiferrodistortive) and displacement (disp) configurations.
  
**Note:**
The Cubic phase was cooled down, whereas Pbam, Pnma20, and R3c were heated up from 0 K.

**Format of the MD output files:**
  Column 1 : temperature (K)
  Column 2 : x component of <quantity>
  Column 3 : y component of <quantity>
  Column 4 : z component of <quantity>

- lattice: Subfolder containing the lattice-related simulation data.
  
**Format of the lattice files:**
  Column 1 : temperature (K)
  Column 2 : lattice direction (a, b, c), corresponding to x, y, z
  Column 3 : lattice constant (Å)

## 6. Electric_Field
This folder contains the polarization results under applied electric fields at different temperatures for the cubic phase.

**File description:**
- cubic-200K.txt, cubic-300K.txt, cubic-400K.txt, cubic-500K.txt: Polarization results under applied electric fields at 200 K, 300 K, 400 K, and 500 K, respectively.
- README.txt: Specific column definitions for the data in this folder.
