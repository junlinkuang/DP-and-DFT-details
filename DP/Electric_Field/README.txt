================================================================================
README: Polarization–electric field hysteresis loop data for PbSnO3
================================================================================

Files:
  cubic-200K.txt : P–E hysteresis loop at 200 K 
  cubic-300K.txt    : P–E hysteresis loop at 300 K 
  cubic-400K.txt  : P–E hysteresis loop at 400 K
  cubic-500K.txt  : P–E hysteresis loop at 500 K

Format (identical for all files):
  Column 1 : electric field E (MV/cm)   -> read as x
  Column 6 : polarization P (µC/cm²)   -> read as y
